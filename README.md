# Timelooks Bengali Luxe

Build a high-converting, single-product luxury watch e-commerce landing page & full Admin Panel completely in Bengali for "TIMELOOKS" (Slogan: TIME. STYLE. YOU).

1. BRANDING & THEME (Matching Attached Logo):

- Dark Luxury Theme (#0f0f12 charcoal/black background, vibrant #f97316 amber orange accents, glassmorphism cards, crisp white text).

- Brand Name: TIMELOOKS in header.

2. HERO & LANDING PAGE SECTIONS:

- Typewriter Animation in Bengali for slogans.

- Luxury watch hero image with amber glow effect.

- Key product features in Bengali (ওয়াটারপ্রুফ, প্রিমিয়াম স্ট্র্যাপ, ১ বছরের ওয়ারেন্টি).

- Customer Reviews & Ratings section.

- Mobile Sticky "অর্ডার করুন" Bottom Bar.

3. CHECKOUT & BOGURA THANAS:

- Order Form: Customer Name, Phone Number, Address.

- District Selector: Must default/include "বগুড়া" (Bogura).

- Thana Selector: Must list all Bogura Thanas including "শাহজাহানপুর" (Shajahanpur), "বগুড়া সদর", "শেরপুর", "শিবগঞ্জ", etc., plus custom text input option.

- Dynamic Shipping: Dhaka = ৳80, Outside Dhaka = ৳150 (Auto total calculation).

- Payment: Cash on Delivery.

4. FULL ADMIN PANEL (/admin):

- Secure login for admin.

- Dashboard with Sales Analytics (Total Sales, Pending Orders, Delivered Orders).

- Order Management Table: View customer details, update status (Pending, Shipped, Delivered, Cancelled), filter by status, and export to CSV.

- Product & Price Settings: Change product title, Bengali description, price, delivery charges, and stock directly from admin.

Keep everything modular, responsive, and clean.
